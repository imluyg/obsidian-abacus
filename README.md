# Abacus

**把写作量当账本记。** 一个 Obsidian 插件：汉字与英文词分开统计，按文件、按天、按项目记账。

> English version: [README.en.md](./README.en.md)
>
> An Obsidian plugin that treats your writing output as a ledger: CJK characters and English words counted separately, tracked per file, per day, per project. Fully local — no network, no telemetry.

---

## 为什么不直接用现成的字数插件

多数字数插件用「总量重算取差」：今天库里有 30 万字、昨天 29.8 万，差 2000 就算今天写了 2000。这个模型有个致命问题——**任何批量导入、删除、移动文件，都会变成假的写作量**。

Abacus 把两件事分开存：

```
快照（存量）  每个文件现在多少字，可随时全量重建
账本（流量）  逐次追加的事件，永不改写
```

任何统计——日、周、月、项目、连续天数——都是账本的视图。所以：

- 批量导入不会变成「今天写了 14 万字」
- 重命名文件不会产生一次负增长
- 删掉快照文件也不会丢历史，只有账本是不可重建的

## 特性

- **分量计数**：汉字按字、英文/数字按词，两个分量从不合并成一个「总字数」
- **每日记账**：今日、本周、本月、全库；近 7 / 30 天柱状图
- **连续写作天数**：今天还没写不算断，昨天没写才算
- **目标**：可选每日/每周目标，面板显示进度条
- **项目**：按路径分组，可点开看该项目下的文件；规则可细化到单本书
- **周报 / 年度报告**：写入指定目录，年度报告带 HTML 热力图
- **CSV 导出**：按天汇总，方便在 Excel 或脚本里再分析
- **账本自检**：坏行、截断、重复、未来时间戳，异常常驻显示
- **多设备安全**：账本按设备分文件，同步冲突不会互相覆盖
- **可选写回属性**：把字数写进笔记 frontmatter，供 Bases / Dataview 排序筛选

## 安装

尚未上架社区插件市场，两种方式：

**手动**：把 `main.js`、`manifest.json`、`styles.css` 放进库里的 `.obsidian/plugins/abacus/`，然后在「设置 → 第三方插件」里启用。

**BRAT**：安装 BRAT 插件，Add Beta Plugin 填本仓库地址。

## 数据与隐私

**插件不联网。** 代码里没有任何 `fetch`、`requestUrl`、WebSocket 或遥测调用；没有任何外部 URL。

所有数据只写在本机这个位置：

```
.obsidian/plugins/abacus/
├── data.json              设置
└── stats/
    ├── snapshot.json      存量快照（可删，会自动重建）
    └── ledger/
        └── 2026-11.<设备id>.jsonl   按月追加的事件账本
```

账本每行是一个事件，包含**笔记路径**和字数，不含笔记正文：

```json
{"t":1763200000000,"p":"创作/小说/1/第一章.md","add":[820,12],"del":[35,0],"src":"edit"}
```

设备 id 随机生成、存在 `localStorage`（不放 `data.json`，否则会跟着同步走，多设备就又是同一个 id）。

## 设计要点

**账本只追加，不改写。** 每条事件有 `src` 说明来源：`baseline`（首次建库，不计入写作）、`edit`（本机编辑）、`scan`（离线期间的变化）、`delete`（删文件，不算写作）。

**首次建库不写账本。** 否则几十万字会全部砸在启用插件的那一天。

**追加前修尾。** 如果账本文件末尾是同步冲突留下的半行，先截掉再追加——否则新行会粘在坏行后面，那一行就永久损坏了。

**写放大很小。** 文件大小与上次写完后一致就直接追加，耗时与文件大小无关；大小对不上才退回「读全文 → 修尾 → 整写」。

## 开发

```bash
npm install
node build.mjs        # 类型检查 + 打包出 main.js
node build.mjs --test --vault=/path/to/vault   # 测试，含真实库全量扫描
node deploy.mjs       # 安装到 .obsidian/plugins/abacus
```

构建不用 esbuild：它要 spawn 子进程走管道，在受限环境里会 EPERM。`build.mjs` 用 TypeScript 自己的 `transpileModule` 逐文件编译，再用一个几十行的模块表拼成单文件，全程在当前进程内完成。

## 已知限制

- 只统计 Markdown；靠 Dataview 渲染、数据全在 YAML 属性里的笔记，正文部分几乎不计入
- 计数口径固定（汉字按字、英文按词，默认排除 frontmatter 与代码块），暂不提供自定义正则
- 桌面与移动端都可用，但移动端未做过真机验证
